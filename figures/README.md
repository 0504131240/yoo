# איורים (Anatomy)

`circulation/build.mjs` בונה את `circulation.html` (מחזור הדם) בשורש האתר.

```bash
cd figures/circulation && node build.mjs --fragment && cp circulation-site.html ../../circulation.html
```

הקבצים ב-`kit/` וב-`scripts/` הועתקו מהכלי [Anatomy](https://github.com/wheresryan22/anatomy) (רישיון MIT, ראו `kit/LICENSE`).
